# Principios y Prácticas de SEM y MLM (5a ed.)
# Efraín García Sánchez

Materiales del curso **Principios y Prácticas de SEM y MLM 5 ed. - 2026**.

## Contenidos

- `temas/`: presentaciones originales en Quarto/RevealJS.
- `principios_slides/`: versiones para estudiantes en HTML vertical autocontenido y sus archivos `.qmd`, sin código de soluciones.
- `practicas_ejercicios/`: cuadernos `.qmd` con prácticas y ejercicios para ejecutar en clase. Las prácticas conservan el código guiado; los ejercicios incluyen espacios para escribir soluciones.
- `data/`: bases de datos y archivos auxiliares usados en las prácticas.
- `imagenes/`: imágenes y recursos visuales usados en las presentaciones y documentos.

## Uso recomendado

1. Abrir el proyecto desde la carpeta raíz. SIEMPRE abrir el archivo `.Rproj`
2. Ejecutar primero `practicas_ejercicios/Sesion_1_0_presentacion_practicas.qmd` para instalar y cargar los paquetes necesarios.
3. Seguir los documentos de `practicas_ejercicios/` durante las prácticas.
4. Consultar los HTML de `principios_slides/` como material de lectura para estudiantes.
